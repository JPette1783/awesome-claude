## Editorial notes

Open SWE is a practical reference implementation for teams that want to run
coding agents against their own repositories without building the orchestration
layer from scratch. It mirrors patterns used by engineering teams at Stripe,
Ramp, and Coinbase for internal coding agents.

The framework composes on LangGraph and the Deep Agents harness. Each task
runs in a dedicated cloud sandbox (Modal, Daytona, Runloop, or LangSmith),
executes the agent loop with ~15 curated tools, and opens a draft PR on
completion. Parallel tasks get separate sandboxes with no queuing.

Trigger surfaces include Slack mentions, Linear comments with `@openswe`, and
GitHub PR comment replies. A web dashboard handles authentication, team
settings, and direct chat.

Relevant for builders who want a self-hosted, customizable coding agent
baseline with sandbox isolation, multi-platform triggers, and subagent
orchestration built in.
